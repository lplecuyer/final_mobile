# Guide d'utilisateur

### Ajout de jeux

- Vos jeux viennent en premier lieu de la base de donnée de Steam, il vous faudra donc les importer pour pouvoir commenter et reviewer vos jeux

![alt text](image.png)

### modifier l'etat de completion d'un jeu (si il est importé)

- une fois vos jeux importés, vous aurez accès à la modification du  niveau de completion de vos jeux, simplement en cliquand dessus à partir de votre profil. de là, vous pourrez selectionner votre niveau de progression et le sauvegarder

![alt text](image-1.png)

### Ajout ou modif de Review

- Pour ajouter des reviews sur un jeu, selectionner un jeu qui vous appartient dans la liste jeu jeu et appuyez sur Ajouter une Review, si le bouton n'est pas présent, c'est parce que vous ne possédez pas le jeu! Une fois votre review envoyée, vous aurez la possibilité de le modifier à votre guise.
