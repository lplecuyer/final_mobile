# Standards de Developpement

### UI
<p> Nous avons décidé d'aller vers un format qui s'apparente beaucoups a celui de Steam, puisque notre application en est fortement inspirée. Niveau couleur, nous avons prit la même palette que l'application mobile de Steam. Nous avons également choisi un logo qui sera représenté partout dans l'application. Pour uniformiser l'apparence de l'app soit que ça casse les yeux, nous n'avons que 3 format de typographies définies en css, un titre, un gros texte et un petit texte </p>

### UX
<p> Niveau navigation, on s'est dit que ça serait plus beau d'avoir des boutons à apparence personnalisés, c'est pour ça que notre bouton retour est notre logo. La navigation est facile et simple a utiliser, sans avoir des écrans qui s'empile tout le temps, il y a toujours moyen de revenir en arrière. Nous avons aussi utilisé un mélange de Toast et d'alerts pour les pop ups afin d'avertir l'utilisateur de nos attentes dans ses actions </p>

### code
<p> nos fichiers de code sont regroupés en sous-dossiers afin de mieux se retrouver. Le nom des fichiers est significatif à leur fonctionnalité. malgré le UI en français de l'application, nos variables sont toutes en anglais. Le nom des méthodes sont significatives </p>

### BD
<p> Notre bd est très simple et facile à comprendre. Le nom des tables explique clairement ce qu'elles contiennent. L'utilisation des clés primaires et étrangères forment une harmonie à travers nos tables afin de conserver une belle intégrité des données </p>
